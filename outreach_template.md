## 4. DYNAMIC MERGE FIELDS SPECIFICATION

The accompanying `pipeline.py` script automatically parses the ClinicalTrials.gov v2 REST API and populates the following merge fields for targeted lead generation:

| Merge Field | Description | Source Field in API |
| :--- | :--- | :--- |
| `{{NCT_ID}}` | ClinicalTrials.gov Identifier | `protocolSection.identificationModule.nctId` |
| `{{STUDY_TITLE}}` | Full Brief Title of Study | `protocolSection.identificationModule.briefTitle` |
| `{{STUDY_TITLE_SHORT}}` | Truncated study title for subject lines | Derived (first 45 chars) |
| `{{PI_NAME}}` | Responsible Party / Principal Investigator Full Name | `protocolSection.sponsorCollaboratorsModule.responsibleParty.investigatorFullName` |
| `{{PI_LAST_NAME}}` | PI Last Name (for salutation) | Derived from full name |
| `{{PI_TITLE}}` | Academic / Clinical Title | `protocolSection.sponsorCollaboratorsModule.responsibleParty.investigatorTitle` |
| `{{PI_AFFILIATION}}` | Stated Affiliation | `protocolSection.sponsorCollaboratorsModule.responsibleParty.investigatorAffiliation` |
| `{{LEAD_SPONSOR_NAME}}` | Sponsor Name | `protocolSection.sponsorCollaboratorsModule.leadSponsor.name` |
| `{{COMPLETION_DATE}}` | Actual or Anticipated Study Completion Date | `protocolSection.statusModule.completionDateStruct.date` |
| `{{PRIMARY_COMPLETION_DATE}}` | Primary Completion Date | `protocolSection.statusModule.primaryCompletionDateStruct.date` |
| `{{DAYS_OVERDUE}}` | Calendar days past the 1-year statutory deadline | Calculated relative to current date |
| `{{DAILY_PENALTY}}` | Statutory daily penalty ($15,107) | 45 CFR § 102.3 statutory rate |
| `{{POTENTIAL_CMP_ACCRUED}}` | Theoretical accrued exposure | `{{DAYS_OVERDUE}}` × $15,107 |
| `{{PI_EMAIL}}` | Central contact / investigator email | `protocolSection.contactsLocationsModule.centralContacts` or facility contacts |
| `{{LOCATION_FACILITY}}` | Primary clinical site facility | `protocolSection.contactsLocationsModule.locations[0].facility` |
| `{{LOCATION_CITY_STATE_ZIP}}` | Location City, State, Zip | `protocolSection.contactsLocationsModule.locations[0]` |
